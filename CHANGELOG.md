# История изменений

## 0.4.0

- **Поездка на несколько дней** по региону: 2–5 объектов, переезды в выгодном порядке, ночлег
  у каждого и общий план по дням.
- **Публикация отчёта ссылкой** на GitHub Pages с QR-кодом для телефона.
- **Офлайн-пакет для телефона**: своя карта района MBTiles, GPX, KML и отчёт.
- Маркированные пешие тропы в приоритете; трек и в KML.

## Ранее

- Путь без троп обходит озёра, через болота и реки — только когда это выгодно.
- Предупреждения о часах работы, сезонах ООПТ, зимниках и перевалах.
- Варианты маршрута: полдня, полный день, два дня с ночёвкой.
- Близкие связанные объекты объединяются в одну остановку.
- Трек GPX хранится в памяти и скачивается, как только маршрут готов.
- Быстрый поиск соседей, план по дням и ночлег, интерактивные HTML-карты.
- Переработка: одно окно, популярные попутные объекты, городской режим, фирменные карты и отчёты.
- Первая версия: плагин QGIS, который строит экскурсию к туристическому объекту.
