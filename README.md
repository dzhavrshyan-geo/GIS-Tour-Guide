# ГИС-экскурсовод — плагин QGIS

Пишете название туристического объекта, например **«вулкан Горелый»**, — плагин сам:

1. **Находит объект** и его координаты (OpenStreetMap / Nominatim, при неудаче — Википедия).
   Если мест с таким названием несколько, их можно выбрать из списка.
2. **Строит обзорную карту в масштабе региона**: граница субъекта, город, откуда едем,
   дорога на машине, объект. Если регион огромный (Камчатка, Якутия), на карте есть
   врезка «Подъезд крупнее».
3. **Рассказывает, как добраться**: дорога на машине от ближайшего города (или от места,
   которое вы укажете) с перечнем трасс и километров, где кончается проезжая дорога,
   и раздел «Как добраться» из Викигида (автобусы, вахтовки, самолёты).
4. **Ищет попутные объекты** в прямоугольной зоне ±3…30 км вокруг объекта: вулканы,
   вершины, пещеры, водопады, горячие источники, гейзеры, смотровые площадки, музеи,
   исторические памятники и т. п. (OpenStreetMap + статьи Википедии с координатами).
5. **Прокладывает оптимальный маршрут экскурсии**: выбирает порядок обхода (задача
   коммивояжёра — кольцо от машины или в одну сторону) и ведёт пеший маршрут по
   дорогам и тропам, а где троп нет — **по рельефу**: самый быстрый для пешехода путь
   по цифровой модели рельефа с обходом склонов круче 35°.
6. **Строит карту-схему окрестностей** с пронумерованными точками, маршрутом
   (по тропам — сплошной линией, без троп — пунктиром), таблицей объектов и рельефом.
7. **Даёт советы**: время в пути и световой день, профиль высот, набор высоты,
   что надеть (по прогнозу погоды на вершине), сколько взять воды и еды на группу,
   есть ли рядом магазины и заправки, ООПТ и пропуска, медведи/клещи/змеи, газы у фумарол,
   снаряжение для пещер и горячих источников, регистрация в МЧС.
8. **Собирает описания, фотографии и заметки туристов** из открытых источников:
   Википедия, Викигид, фотографии Викисклада с подписями авторов, наблюдения и заметки
   туристов-натуралистов iNaturalist («кого можно встретить» — например, суслики у
   подножия Горелого).

Результат — группа слоёв в проекте, два макета печати (их можно править в QGIS),
PNG/PDF карт, трек **GPX** для телефона и **HTML-отчёт** со всем перечисленным.

## Установка

1. Скачать архив `gis_tour_guide.zip` (или собрать: `python tools/build_zip.py` → `dist/`).
2. QGIS → «Модули» → «Управление и установка модулей» → «Установить из ZIP».
3. В меню «Модули» появится «ГИС-экскурсовод» и кнопка на панели инструментов.

Нужен QGIS 3.22 или новее и доступ в интернет. Ключи API не нужны — все источники открытые.

## Как пользоваться

**Вкладка «Экскурсия»**

| Поле | Что значит |
|---|---|
| Туристический объект | Название: «вулкан Горелый», «водопад Кивач», «пещера Шульган-Таш». Можно добавить регион: «Горелый, Камчатка». «Найти» показывает варианты в списке «Найдено». |
| Откуда ехать | Город или адрес. Пусто — от ближайшего города. Если от указанного места проезда нет (остров, Камчатка из Москвы), дорога строится от ближайшего города, а отчёт подскажет про самолёт/паром. |
| Зона поиска | Прямоугольник ±N км от объекта (3…30), в нём ищутся попутные объекты. |
| Попутных объектов | Сколько лучших объектов включить в маршрут (по умолчанию 8). |
| Маршрут | Кольцевой (вернуться к машине) или в одну сторону. |
| Дата поездки, туристов в группе | Для прогноза погоды, светового дня и расчёта воды/еды. |
| Рельеф | «Автоматически» — открытые тайлы высот Terrain Tiles (AWS, SRTM ~30 м); или растровый слой ЦМР из проекта (любая система координат); или без рельефа. |
| Подложка карты-схемы | OpenTopoMap (топокарта с тропами), OpenStreetMap, «Только рельеф — простая схема» (отмывка и раскраска высот) или без подложки. |

«Создать экскурсию» запускает сбор в фоне (окно не замирает, есть «Отмена» и журнал).

**Вкладка «Объекты»** — все найденные объекты с баллами интереса. Отметьте, что хотите
посетить (или снимите лишнее), и нажмите **«Перестроить маршрут»**. Двойной щелчок —
показать объект на карте.

**Вкладка «Отчёт»** — HTML-отчёт; кнопки открывают его в браузере, папку результатов
и макеты карт в редакторе макетов QGIS.

### Что получается в папке результатов

```
<папка>/<объект>_<дата_время>/
  report.html          отчёт (открывается в любом браузере, можно отправить)
  overview_map.png/.pdf  обзорная карта региона
  scheme_map.png/.pdf    карта-схема маршрута
  profile.png          профиль высот с номерами объектов
  route.gpx            трек и точки для навигатора / телефона
  tour.gpkg            слои: точки маршрута, другие объекты, маршрут, дорога, зона, регион, фото
  dem.tif              рельеф зоны (GeoTIFF)
  photos/              фотографии
```

В проекте у слоёв «Точки маршрута» и «Фотографии» настроены подсказки (Map Tips):
наведите мышь на точку — появится фото и описание.

## Как это устроено

| Шаг | Источник |
|---|---|
| Координаты объекта, граница региона, название места старта | [Nominatim](https://nominatim.org) (OpenStreetMap) |
| Попутные объекты, магазины, заправки, вода, ООПТ, ближайший город | [Overpass API](https://overpass-api.de) (OpenStreetMap), резервные серверы mail.ru и kumi.systems |
| Описания и картинки | [Википедия](https://ru.wikipedia.org), Викиданные |
| «Как добраться», «Безопасность», «Ночлег» | [Викигид](https://ru.wikivoyage.org) |
| Дорога на машине и пешие маршруты по тропам | [OSRM](https://project-osrm.org) на серверах [FOSSGIS](https://routing.openstreetmap.de) |
| Рельеф | [Terrain Tiles](https://registry.opendata.aws/terrain-tiles/) (AWS Open Data) или ваш слой ЦМР |
| Погода | [Open-Meteo](https://open-meteo.com) (с поправкой на высоту точки) |
| Фото | [Викисклад](https://commons.wikimedia.org) — снимки рядом с каждым объектом |
| Животные и заметки туристов | [iNaturalist](https://www.inaturalist.org) |

* **Порядок обхода** — точное решение задачи коммивояжёра (Хелд — Карп) до 12 точек,
  дальше — ближайший сосед + 2-opt. Расстояния — по пешеходной сети OSRM, с «штрафом»
  за отход от троп.
* **Путь по рельефу** — A* по сетке высот; время шага — по функции пешехода Тоблера
  (вне троп ×0,6 скорости), склоны круче 20° штрафуются, круче 35° непроходимы.
  Используется для концов маршрута в стороне от троп (дальше 150 м) и там, где тропа
  делает огромный крюк.
* **Время в пути** — по профилю высот (Тоблер) плюс ~25 минут на осмотр каждого объекта.
* Ответы сервисов кэшируются (папка `cache/gis_tour_guide` в профиле QGIS), запросы к
  Nominatim идут не чаще раза в секунду — как просят правила открытых сервисов.
  Если какой-то сервис недоступен, экскурсия всё равно строится, а в журнале будет
  предупреждение.

## Ограничения

* **Отзывы с TripAdvisor, Яндекс.Карт, 2ГИС, Tripster и т. п. плагин не собирает**: у них
  нет открытого API, а автоматический сбор запрещён их правилами. Вместо них — подписи
  авторов фотографий Викисклада, тексты Викигида и заметки наблюдателей iNaturalist.
  Если найдётся открытый источник отзывов с API — его легко добавить (`extras.py`).
* Путь по рельефу не знает о реках, озёрах, болотах и зарослях — только о высотах.
  Участки «без троп» на карте отмечены пунктиром, сверяйтесь с местностью.
* Автомобильный профиль OSRM обычно не прокладывает путь по грунтовкам `highway=track`: «конец дороги» —
  это конец дороги для легковой машины; дальше по грунтовке часто можно проехать
  на внедорожнике (в отчёте об этом сказано).
* Прогноз Open-Meteo — на 16 дней вперёд. Для более поздней даты одежда подбирается
  по сезону, широте и высоте — проверьте прогноз ближе к поездке.
* Сведения собираются автоматически из открытых источников: проверяйте актуальность
  дорог, правил посещения ООПТ и вулканической активности.

## Для разработчиков

```
gis_tour_guide/
  planner.py   сборка экскурсии (без QGIS): поиск → объекты → дорога → маршрут → сведения
  geocode.py   Nominatim + Википедия, граница региона
  osm.py       Overpass: категории объектов, магазины, ООПТ, города
  wiki.py      Википедия, Викигид, Викиданные, Викисклад
  routing.py   OSRM: машина, пешеход, сводка по дорогам, участки без троп
  terrain.py   тайлы высот, профиль, набор высоты, Тоблер, путь по рельефу (A*)
  tsp.py       порядок обхода
  extras.py    погода, iNaturalist, опасные животные
  advice.py    правила «что надеть и что взять»
  report.py    HTML-отчёт, GPX, профиль высот
  maps.py      слои, стили, GeoPackage, макеты печати (QGIS)
  dem_layer.py высоты из слоя ЦМР проекта (QGIS)
  task.py      фоновые задачи QgsTask
  dialog.py    окно плагина
```

Тесты (без сети — ответы сервисов подделаны в `tests/fake_services.py`):

```
python -m unittest discover tests      # test_pipeline.py — нужен Python из QGIS (модуль qgis)
```

`test_core.py` работает на любом Python с numpy; `test_pipeline.py` прогоняет весь путь
на настоящем QGIS без окна: поиск, маршрут, рельеф, слои, макеты, экспорт PNG/PDF, отчёт,
окно плагина. Декодирование высот проверено на настоящем тайле над Горелым
(`tests/fixtures`, вершина — 1829 м).

Иконка: `python tools/make_icon.py`. Архив для установки: `python tools/build_zip.py`.
